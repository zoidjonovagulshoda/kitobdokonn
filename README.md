# Sahifa kitob doʻkoni

Onlayn kitob doʻkoni sayti: katalog, kitoblarni bepul oʻqish, savat, yetkazib berish va toʻlov bosqichlari.

Sayt bitta `index.html` faylidan iborat. Server yoki qoʻshimcha dastur kerak emas.

## GitHub Pages'da ochish

1. GitHub'da yangi repozitoriya yarating (masalan, `sahifa`). U **Public** boʻlishi kerak.
2. **Add file → Upload files** orqali `index.html`, `README.md` va `.nojekyll` fayllarini yuklang va **Commit changes** ni bosing.
3. **Settings → Pages** boʻlimiga oʻting.
4. **Source** qismida **Deploy from a branch** ni tanlang. Branch: `main`, papka: `/ (root)`. **Save** ni bosing.
5. 1–2 daqiqadan keyin sayt shu manzilda ochiladi: `https://FOYDALANUVCHI-NOMI.github.io/sahifa/`

## Eslatma

- Kitoblar va matnlar namuna sifatida yozilgan. Ularni `index.html` ichidagi `BOOKS` roʻyxatida oʻzgartirish mumkin.
- Toʻlov namuna rejimida ishlaydi: pul yechilmaydi. Haqiqiy toʻlov uchun Click, Payme yoki Uzum merchant hisobi va server kerak.
- Savat va oʻqilgan bob brauzerning oʻzida saqlanadi.
